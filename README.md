## Installed Mods & Details

Running on private hardware with the following mod setup:

| Category | Mod Name | Purpose |
| :--- | :--- | :--- |
| **Framework** | `CF` & `Dabs Framework` | Core modding framework dependency |
| **Expansion** | `DayZ-Expansion-Bundle` & `Licensed` | Expansion mechanics, mapping, and AI base |
| **Base Building** | `RaG_Core` & `RaG_BaseItems` | Extended base building items and structures |
| **Survival** | `RaG_Hunting_Cabin` & `KM_WaterWell` | Custom survival shelters and buildable water wells |
| **Environment** | `BuildingWarmth` | Dynamic warmth effects when indoors near heat sources |
| **Vehicles** | `4KBOSSKVehiclePackage` | Custom drivable vehicles |
| **Vehicles** | `RUSForma_Motorcycles` & `Bicycles` | Motorcycles, pedal bikes, and travel options |
| **Animation & Immersion** | `Survivor Animations` & `Flying Birds!` | Enhanced player animations and environmental immersion |
| **Combat & Mechanics** | `Keep It Dead` & `NoMoreRuinedGuns` | Corpse persistence timers & weapon durability tweaks |
| **Gear** | `Unknown Ghillie Mod` | Custom ghillie suit variants |
| **Loot System** | `Search For Loot Improved` & `GarbageSearch` | Interactive container searching and loot mechanics |
| **Progression** | `Advanced Battle Pass v2` | Season progression and rewards system |
| **AI Content** | `Dynamic AI Missions` | Dynamic AI encounters and world events |
| **Admin Tools** | `VPPAdminTools` | In-game server administration suite |
